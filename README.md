# Rightcontroller
A little AHK script to make rightctrl a master keybind!!!
This was originally made for me when i had a broken FN key and a broken left and right arrow keys

## Controls :

### 1-RightCtrl + 1 = Mute audio
### 2-RightCtrl + 2 = Volume down
### 3-RightCtrl + 3 = Volume up
### 4-RightCtrl + 4 = Mute microphone
### 5-RightCtrl + 5 = Brightness up
### 6-RightCtrl + 6 = Brightness down
### 7-RightCtrl + 7 = Just WIN+P but better since it needs one hand?
### 8-RightCtrl + 8 = Opens settings
### 9-RightCtrl + 9 = Locks desktop
### 10-RightCtrl + 0 = Just ALT tabs
### 11-RightCtrl + - = Opens calculator
### 12-RightCtrl + = = Opens up quick settings
