# Rightcontroller
A little AHK script to make rightctrl a master keybind!!!
This was originally made for me when i had a broken FN key and a broken left and right arrow keys
## NOTE : You will need to download Soundvolumeview From nirsoft!!!!

## Controls :

-RightCtrl + 1 = Mute audio
-RightCtrl + 2 = Volume down
-RightCtrl + 3 = Volume up
-RightCtrl + 4 = Mute microphone (This needs soundvolumeview from nirsoft)
-RightCtrl + 5 = Brightness up
-RightCtrl + 6 = Brightness down
-RightCtrl + 7 = Just WIN+P but better since it needs one hand?
-RightCtrl + 8 = Opens settings
-RightCtrl + 9 = Locks desktop
-RightCtrl + 0 = Just ALT tabs
-RightCtrl + - = Opens calculator
-RightCtrl + = = Opens up quick settings

Note : You can change controls = - 9 and 8 to do something else if you know how to code in autohotkey!!!
